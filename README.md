# 야구 매거진 사이트

뉴스 읽기 · 게시판(글/댓글) · 매거진 구매 연결, 세 가지 기능을 가진 사이트입니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 사이트의 뼈대. 이 파일을 브라우저로 엽니다. |
| `css/style.css` | 디자인 (색, 글꼴, 배치) |
| `js/config.js` | **설정** — 사이트 이름, DB 연결 정보, 스마트스토어 주소, 카테고리 |
| `js/data.js` | 데이터 읽기/쓰기 |
| `js/app.js` | 화면 그리기 |
| `supabase/schema.sql` | DB 표를 만드는 명령 |

## 1단계: 일단 열어 보기

`index.html` 을 더블클릭하면 브라우저에서 열립니다.
`js/config.js` 에 Supabase 정보가 들어 있으면 실제 DB의 기사와 글이 보입니다. 비어 있으면 샘플 기사만 보이는 **샘플 모드**입니다.

## 2단계: 실제 DB 연결 (Supabase)

게시판 글과 댓글이 모든 방문자에게 보이려면 DB가 필요합니다. Supabase 는 무료로 시작할 수 있습니다.

1. https://supabase.com 에서 가입하고 새 프로젝트를 만듭니다. (지역은 Seoul 권장)
2. 왼쪽 메뉴의 **SQL Editor** 를 열고, `supabase/schema.sql` 내용을 전부 붙여넣은 뒤 **Run** 을 누릅니다.
3. 프로젝트 설정의 API 항목에서 두 값을 복사합니다.
   - Project URL
   - anon (또는 publishable) 키
4. `js/config.js` 의 `SUPABASE_URL`, `SUPABASE_ANON_KEY` 에 붙여넣고 저장합니다.
5. 브라우저를 새로고침합니다. "첫 기사: DB 연결 성공" 이 보이면 완료입니다.

> 주의: `service_role` (또는 secret) 키는 절대 넣지 마세요. 그 키는 모든 권한을 가진 관리자용입니다.

## 기사 올리기 (관리자만)

기사는 관리자 계정만 쓰고, 고치고, 지울 수 있습니다. 다른 사람은 주소를 알아도 DB가 거부합니다.

**관리자 지정 (처음 한 번)**

1. 사이트 오른쪽 위 "로그인" → "회원가입"으로 관리자 계정을 만들고, 받은 메일의 링크를 누릅니다.
2. Supabase 의 SQL Editor 에서 아래를 실행합니다. (이메일만 바꾸세요)

```sql
insert into public.admins (user_id)
select id from auth.users where email = '관리자@이메일.com'
on conflict do nothing;
```

3. 사이트에서 다시 로그인하면 메뉴 아래쪽에 **기사 관리**가 나타납니다.

**기사 쓰기**

메뉴 → 기사 관리에서 제목, 카테고리, 요약, 사진, 본문을 입력하고 "기사 올리기"를 누릅니다.
사진은 파일을 직접 올리거나 주소(https://)를 붙여넣을 수 있습니다.
아래 목록에서 제목을 누르면 수정, "삭제"를 두 번 누르면 삭제됩니다.

## 스마트스토어 연결

`js/config.js` 의 `STORE_URL` 에 스마트스토어 주소를 넣으면 "매거진 구매" 버튼이 그 주소로 이동합니다.

## 인스타그램 연결

`js/config.js` 의 `INSTAGRAM_URL` 에 인스타그램 계정 주소를 넣으면, 메뉴 아래쪽 Instagram 버튼이 그 계정으로 이동합니다.

## 로그인과 게시판

- 글과 댓글은 **로그인한 회원만** 쓸 수 있습니다. 읽기는 누구나 가능합니다.
- 글쓴이 닉네임은 가입할 때 정한 닉네임으로 DB가 직접 채웁니다. (남의 닉네임 사칭 불가)
- 본인 글·댓글은 본인이 삭제할 수 있고, 관리자는 모든 글을 삭제할 수 있습니다.
- 말머리는 `js/config.js` 의 `BOARD_CATEGORIES` 에서 바꿉니다. `공지` 말머리는 관리자만 쓸 수 있고 목록 맨 위에 고정됩니다.
- 게시판은 한 쪽에 20개씩 보이고, 말머리별 보기와 게시판 안 검색이 됩니다.

## 배포 (인터넷에 올리기)

이 폴더의 파일을 그대로 정적 호스팅(GitHub Pages, Netlify 등)에 올리면 됩니다.
`index.html` 이 맨 위에 있어야 합니다. 빌드 과정은 없습니다.

## 아직 없는 기능

- 휴대폰 번호 인증 (문자 발송 업체 계약이 필요해 아직 이메일 로그인입니다)
- 이메일 인증 (지금은 꺼져 있음 — Supabase 의 Authentication 설정에서 다시 켤 수 있음)
- 글·댓글 수정, 신고, 추천
